03 / 作品功能
三重护栏，越界自动回退
01
用户设定范围
参数上下限由用户设定，Agent 只在区间内动作
02
系统硬上限
Kp ≤ 20、Ki / Kd ≤ 10；单步增幅拦截，避免一次调过头
03
越界自动回退
超调 > 20% 或振荡 > 10%，回到最佳稳定参数并醒目提示
仿真 / 真实串口双模式
仿真纯软件、零硬件；实机改参下发 PID、设目标下发 SET_POINT
安全不能靠提示词
护栏与回退写进代码机制，正面回应「怕 AI 乱调把机械弄坏」

05 / 使用说明
五步，完成一次调参
01
连接串口
选协议 Raw / JustFloat / FireWater，刷新端口，115200 8N1，打开串口
02
看波形与数据
实时多通道波形、数据表 I0–I7，支持录制与一键回放
03
配置 AI
填模型、Base URL 与 API Key；Key 仅存当前会话
04
开始调参
切「PID 调参」，选仿真 / 真实串口与策略，填 PID 初值、安全范围、场景提示词
05
看闭环与下发
输入「开始整定，优先压超调」；实机下发 PID / SET_POINT，约 12 秒采集窗口
05 / 使用说明
没有硬件，也能完整体验
零硬件路径

零 Key 路径
切到「数据分析」查看本地响应指标，无需硬件、无需 API Key
