## 重跑方式

```bash
cd ai-serial-assistant-app/promo-video
python prepare-audio.py --engine edge --speed 1.05   # 若改了解说稿
python build-v2.py
npm run render
```

若要压到 4 分钟以内，可用 `--speed 1.15` 重新生成配音。
