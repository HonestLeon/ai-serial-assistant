# AI 串口调试助手

> 一款面向嵌入式 / 硬件调试的桌面工具：把串口数据实时画成波形，用 AI 帮你读懂数据、辅助调参。
> 尤其适合参加**电赛、智能车、RC、RM** 等竞赛、需要频繁调 PID 的同学——把最耗时的试错环节压掉。

![主界面](发布包/images/01-主界面.png)

---

## 它能帮你做什么

- **实时波形**：串口数据自动绘制成多通道曲线，可缩放、平移、显隐通道、导出 CSV / JSON
- **数据表与录制回放**：结构化查看通道数值（I0–I7），一键录制数据流，回放时自动断开实时串口
- **AI 能力**：对接 OpenAI 兼容 API（默认 DeepSeek），数据分析可一键「AI 解释」、PID 调参由对话式智能体自主驱动（原「AI 助手」自由对话已合并进调参面板），并自动携带串口上下文
- **确定性响应分析**：对阶跃响应**本地**计算上升时间、稳定时间、超调率、稳态误差、RMSE——不依赖 AI 也能跑
- **PID 辅助调参**：**对话式调参智能体**——自动完成「查数据 → 改参数 → 设目标 → 看结果 → 再决策」的闭环，参数受用户配置范围 + 系统护栏三重校验、越限自动回退；内置电机 / 串级位置 / 倒立摆三种仿真策略，可离线体验完整调参闭环，也支持真实串口实机调参
- **离线模拟**：无需硬件，内置二阶欠阻尼阶跃响应，用来验证整套分析与调参链路

## PID Agent 策略工具（第一版）

在原有五个基础工具之上，增加可由 AI 选择的确定性策略：模型决定何时使用，策略复用本地算法完成一次调整和验证，底层继续执行参数范围校验、增幅限制与安全回退。

| 策略 | 功能 | 适用范围 |
| --- | --- | --- |
| `staged_pid` | 复用 P→PI→PID 分阶段算法，调整一次后重新采集并分析 | 单环 `kp/ki/kd` |
| `recover_pid` | 针对超调或振荡生成保守调整，候选增益不增加，再次验证 | 单环 `kp/ki/kd` |

### 如何使用

1. 配置可用的 AI API、模型名称与 API Key。策略算法本身不调用模型，但 Agent 的选择和对话仍需要 API。
2. 打开「PID 调参」，选择「仿真测试」，建议先用电机速度环，设置初始参数、目标与允许范围。
3. 勾选「启用确定性策略工具（单环试验）」，启动会话。此开关在运行期间不可修改。
4. 可以向 Agent 输入：“先采集当前响应，再使用 staged_pid 做一次调整；依据验证结果决定是否继续，遇到安全回退先解释原因。”
5. 查看消息流中的工具结果。`evaluated` 表示已完成一次验证，不等于达标或效果改善；以验证指标和安全结果为准。
6. 做新旧对照时，结束会话、恢复相同初始配置并关闭策略开关，再运行同一任务。

Agent 通过 `list_pid_strategies` 获取策略说明，通过 `run_pid_strategy` 选择策略。用户无需手动填写工具参数。

### 结果与边界

- 每次调用最多修改一次参数；仿真返回调整前后指标、建议参数、实际应用参数和安全结果。
- 串口窗口未完成时返回 `waiting`；下发并等待复测时返回 `pending_validation`，不能据此宣称设备已确认或调参成功。
- 参数、前馈或目标改变后，旧采集数据不能继续用于策略决策；缺失或无效数据需要重新采集。
- 串级、自定义 PID 参数键、二分搜索和前馈整定策略暂未纳入第一版，继续使用基础工具。
- 已通过本地测试与构建；真实模型新旧对照、真实硬件效果验证尚未完成，暂不作效率或成功率提升承诺。

### 验证命令

在 `ai-serial-assistant-app` 目录运行：

```bash
npm run test:analysis
npm run test:strategies
npm run build
```

`test:analysis` 运行原有 12 组测试；`test:strategies` 验证策略确定性、输入与范围检查、旧数据拒绝、串口等待、停止、恢复、回退及 Agent/电机仿真集成。这些测试不需要 API Key。

完整设计、返回状态与在线对照方案见 [策略工具说明](ai-serial-assistant-app/docs/pid-strategy-tools.md)，代码架构见 [开发文档](ai-serial-assistant-app/README.md)。

## 界面速览

应用主界面自上而下、自左而右分几个区域：

- **左侧边栏「协议与连接」**（SerialPanel）：选协议引擎、配串口参数、填 AI 设置、切 DTR / RTS
- **上部「实时波形」**（WorkspaceChart）：串口数据实时绘制成多通道曲线，**始终可见**；可拖动中间分隔条调整上下区域高度
- **下部分页签栏**：两个标签页，按需切换——
  - **数据**：左侧「数据流 / 数据表」子页签切换，右侧「数据分析」
    - **数据流**：收发数据、自动发送、录制回放、控制响应模拟
    - **数据表**：结构化通道数值（I0–I7）
    - **数据分析**：通道特征统计 EDA + 本地确定性响应分析（上升 / 稳定时间、超调率、稳态误差、RMSE）+ 一键 AI 解释 + 报告导出
  - **PID 调参**：对话式调参智能体（原「AI 助手」能力合并于此，空闲时输入即自由提问）
- **底部状态栏**（StatusBar）：连接状态、Rx / Tx 计数、HEX 切换、主题切换

> 更多截图见 `参赛材料/`：`界面展示.png`、`数据展示.png`、`AI助手展示.png` 等。

## 系统要求

- Windows 10+ / macOS / Linux
- 若从源码运行：Node.js 20.19+（20 系列）或 22.12+，以及 npm；版本要求来自当前 Vite / electron-vite 依赖
- AI 功能需要可访问的 OpenAI 兼容 API（默认 DeepSeek，需自备 Key）

## 快速开始

**方式一：开发预览（需 Node）**

```bash
cd ai-serial-assistant-app
npm install
npm run dev
```

Electron 窗口会自动打开，渲染进程由 Vite 提供热更新。

**方式二：构建安装包**

```bash
npm run dist
```

使用 electron-builder 生成当前平台的安装包。

> 若 Electron 下载失败，可在安装前设置 `ELECTRON_MIRROR` 环境变量。开发启动脚本中的镜像设置不会自动作用于此前执行的 `npm install`。

## 使用指南

### 1. 连接串口

1. 左侧选择数据引擎（**Raw 文本行 / JustFloat 浮点帧 / FireWater 标签:值**；其中 FireWater 走文本行解析）
2. 点「刷新」获取可用端口列表
3. 选端口、波特率、数据位、停止位、校验位、流控（默认 115200, 8N1）
4. 点「打开串口」建立连接
5. 连接后可点 DTR / RTS 按钮切换硬件控制信号

### 2. 收发数据

- **接收**：「数据流」标签实时显示，带时间戳与 Rx / Tx 方向标识
- **数据表**：切到「数据表」看结构化通道数值（I0–I7）
- **发送**：底部输入内容，选文本或 HEX 编码，回车或点发送
- **自动发送**：设间隔（ms）后定时循环发送，断连自动停止

### 3. 录制与回放

- 点「录制」开始记录串口数据流
- 点「回放」会**先自动关闭串口**，再按原始时间间隔重放
- 点「清空录制」清除录制数据

### 4. 实时波形

- 通道列表眼睛图标可显隐对应通道
- **Y 轴**：自动 / 手动（手动可设 Min / Max）
- **X 轴**：鼠标滚轮缩放，按住拖动平移
- **标准化绘图**：悬停提示与导出数据仍使用原始值
- **导出**：CSV / JSON 保存当前波形

### 5. AI 能力

在左侧边栏「AI 设置」统一配置模型、Base URL、API Key（默认 DeepSeek；Key 仅存当前会话，重启需重填）。支持模型：`gpt-4o-mini`、`gpt-4o`、`deepseek-chat`、`qwen-turbo`（Base URL 可改，任意 OpenAI 兼容接口皆可）。

- **数据分析**：本地跑完确定性响应指标后，可点「AI 解释」把响应指标卡与通道特征统计打包成结构化上下文发给模型，得到「为什么超调、往哪调」的说明（无 Key 时确定性指标照常离线可用）
- **PID 调参**：对话式调参智能体由 AI 驱动（详见下一节），原「AI 助手」自由对话能力已合并进该面板——空闲时在右侧输入框提问即可自由问答
- 「实时异常检测 / 协议自动识别」开关位于「AI 设置」区域（当前为预留开关）

### 6. PID 辅助调参（对话式调参智能体）

切换到「PID 调参」标签页：

1. **左栏配置**（开始调参前完成）：
   - 「测试模式」单按键切换——**仿真测试**（纯软件，无需硬件，场景描述自动生成）/ **真实串口**（需先连接设备）；仿真模式下再选「仿真策略」——电机速度环（一阶模型）/ 位置—速度串级 PID / 不稳定二阶系统（倒立摆）
   - **PID 结构**（真实串口模式）：单环 / 串级
   - ① **PID 参数**：每项填初始值 / 最小 / 最大（串级自动展开位置环 + 速度环 6 项；取值范围即护栏第一重约束）
   - ② **信号安全范围**：控制值 / 反馈值 / 目标值各自的 min ~ max（越限告警；与设备量程对齐）
   - ③ **前馈项**：点「＋ 添加前馈项」从模板（线性 / 二次 / sin / cos / 重力补偿 / 常数偏置 / 目标一阶导等）选择并填系数范围
   - ④ **控制场景提示词**（真实串口必填）：描述被控对象、调参目标与特殊约束（如「直流电机速度环，额定转速 3000rpm，带 5:1 减速器，允许 10% 超调」）
   - ⑤ **调参策略**（真实串口必填）：自由文本指导智能体整定实机，如「分阶段 P→PI→PID；先压超调再降稳态误差」
2. 右侧输入任务描述（如「开始整定，优先压超调」），点「开始调参」或回车
3. **智能体自主闭环**：自动「查通道统计 → 改 PID / 前馈 → 设目标做阶跃 → 看响应 → 再决策」；助手思考、工具调用、安全回退、上下文压缩都会在右侧消息流实时展示；**达标后自动收敛并输出最终结论**（前 5 轮为观察期）
4. **安全机制**：参数经「用户配置范围 + 系统上限（Kp≤20、Ki/Kd≤10）+ 单步增幅」三重校验；超调 / 振荡越限自动回退到最佳稳定参数（真实串口模式回退参数会同步下发设备），并以红色警示块醒目提示
5. 运行中在输入框输入文字可**中途纠偏**（steer）；会话结束后输入即**追加新任务**（followUp）
6. **仿真模式**无需硬件即可体验完整闭环；**真实串口**模式改参数会下发 `PID` 指令、设目标会下发 `SET_POINT` 指令并异步采集响应曲线（约 12 秒采集窗口）。嵌入式端联调详见仓库《嵌入式端准备指南》

### 7. 离线体验（无需硬件）

在「数据」标签页的「数据流」子页签点「控制响应模拟」，生成 50 ms 采样的二阶欠阻尼阶跃响应（I0 目标、I1 反馈、I2 控制量、I3 误差）。跑数秒后，切到右侧「数据分析」查看本地响应指标，此过程无需硬件或 API Key。「PID 调参」的仿真模式无需硬件，但由 AI 驱动的 Agent 会话仍需配置 API。

## 常见问题

| 问题 | 解决 |
|------|------|
| 串口打不开 | 检查是否被其他程序占用；必要时以管理员权限运行 |
| 想要浅色 / 深色 | 状态栏主题按钮切换，localStorage 记忆，**默认浅色** |
| AI 没反应 | 检查 Base URL / Key / 模型；Key 仅当前会话有效，重启需重填 |
| 波形不显示 | 确认协议引擎与设备输出格式匹配（Raw：行内数字；JustFloat：二进制浮点帧） |
